# 动态地图、地理编码与路线绘制

仅在网页制作阶段且需要动态地图时读取。路线总览只保留文字站点；地图作为逐日行程内一个共用的现场探索工具，不再绘制整程总览。本技能不使用截图底图，也不在网页运行时做地点搜索、地理编码、路径规划、IP 定位或预取。浏览器地理定位仅在用户点击“使用当前位置”后请求。新攻略使用 `features.nearbyExplore=true`；旧 `explorationSegments[]` 仅作兼容，不作为新攻略的默认录入结构。

## 引擎选择与私有配置

- 全部地点在中国大陆（不含港澳台）时使用百度 JS API GL；涉及境外、香港、澳门或台湾时使用 Google Maps JavaScript API。
- 两种 Browser Key 本地仅放在用户私有配置 `~/.codex/private/travel-guide-builder-v2/baidu-map.local.json`（macOS/Linux）或 `%USERPROFILE%\.codex\private\travel-guide-builder-v2\baidu-map.local.json`（Windows），字段为 `ak` 与 `googleMapsApiKey`。不得写入技能、模板、`trip-*.json`、验证报告或 Git。公开 Pages 先提交 `--public-source` 占位符 HTML，再由 GitHub Actions 从 Repository Secret 注入正式 Browser Key 并只上传 Pages Artifact；部署后 Browser Key 对访客可见属前端 API 的正常特性，必须在地图控制台同时限制正式 Pages 域名、可用 API 和调用额度。
- 地图验收不得用无效密钥替代真实验证。沿用当前受限 Browser Key 即可，不要求额外创建密钥；本地私有构建和 GitHub Actions 分别从本地私有配置与 Repository Secret 注入，密钥值不写入命令行参数、攻略、报告或 Git。
- 本地预览只使用私有 `preview.local.json` 指定的固定来源，流程与 `preview-guide.js` 用法统一见 [固定本机预览来源](web-output-and-publishing.md#固定本机预览来源)。按独立路径挂载攻略，启动前核对端口与产物；不自动换号、停止进程、改 hosts 或调整密钥限制。
- `file://` 通常无法提供可用的 Referer，不能用于真实地图验收；Google Maps 支持 HTTP/HTTPS 网站来源，但浏览器对本地文件或 WebView 可能省略 Referer。使用授权的本地 HTTP 来源和真实 Browser Key 检查底图与覆盖层。若地图服务仍拒绝该来源，不得改用假密钥冒充通过；地图只能如实记为 `degraded`，并说明尚未验证真实底图。
- 百度 bootstrap 必须在 HTML 解析阶段直接加载；Google 直接加载 Maps JavaScript API。适配器分别等待 `window.BMapGL` 与 `window.google.maps.Map`。
- 不自动切换另一家引擎。失败时显示具体诊断和“重试地图”，优先排查 API 启用、结算/额度、Referer 白名单与网络。

## 新攻略的数据与生成顺序

- 研究与逐日数量按 [附近逛逛策略](nearby-explore.md) 执行；候选围绕当天确定目的地，以推荐价值优先，不以顺路或原行程空隙为资格条件。复用 `places[]` 与 `recommendations[]/venueSuggestions[]` 的同一 ID，须有核实坐标、匹配实景图、小红书作者与原帖、`whyNow` 和安排提示；自由窗口只作可选参考。资料不足不凑点，也不以缺道路为由隐藏已核实候选。
- 在生成攻略阶段按住宿起点、正式条目及住宿终点整理当天 A→B→C… 的地面路段。默认驾车路线；每段以实际道路服务核实，保存为 `dayRoadRoutes[].legs[]` 的 Google Encoded Polyline、起终点 ID 和来源类型。需要预先取得并缓存，网页只读取几何，不在打开时请求 Routes API。跨飞机、船舶或其他 `breakGroundRoute=true` 的断点必须分开，不拼接一条驾车线路。
- `nearbyDays[]` 每日一组，允许有原因的不显示日。`dayRoadRoutes[]` 可缺日、缺腿或为空；提供的道路腿须依正式行程顺序组成子序列，不跨断点、不跳过正式停靠点。缺段明确未绘制，仍显示候选卡与点位；不把经纬度直线当道路，也不把候选加入正式路线。
- Google Routes 优先用于境外路线研究；境内继续使用原百度引擎与适用道路证据。记录的几何可离线重绘，不引入在线批量预算、实时路况、候选绕路比较或每次浏览时的路线请求。地图默认驾车仅是图层选择；时间轴里的步行、驾车、摩托车等多方案耗时继续独立按已核验证据展示，不由地图路线推算替换。

## 设计与交互不变量

- 同一天只用一张地图和逐日行程上方的一排日期 Tab；地图内不得重复输出 D1/D2 日期按钮。浅色、低饱和底图保留道路、水域与必要地名，弱化商业和公交图标。正式道路是第一视觉焦点，正式 A/B/C 点位第二，未开启的候选不出现；图层至多三层。路线使用主题 `--guide-action`，候选使用独立的 `--guide-map-candidate`，六套主题保持主次可辨，不把 demo 的青橙值写死到运行逻辑。
- 正式道路使用浅色描边加主题主线，点位为简洁圆标和字母；同坐标起终点合并为 `A/E`，不能双层叠压。候选为更小的圆点，选中态放大。首次打开容纳全部正式点并留边距；候选打开后仍保持正式路线可见，点击候选卡片聚焦点位，点击点位反向定位卡片。候选只提供备选，不改时间轴、导航胶囊或日历。
- “附近逛逛”为当天行程内明确的开关：关闭时卡片和候选点都隐藏；开启后两者同时出现。地点卡可预览图片、打开原帖、查看推荐详情和发起导航。有证据时可在位置说明中写“顺路可去”；值得专程去的注明位置、交通与价值，不强加每店替换方案。无依据时不写“真正顺路”或候选绕路分钟数。
- 地图不堆放交通时间、长段说明和推荐理由；这些留在现有紧凑时间轴及候选卡片。成功加载后隐藏调试/成功状态文案；失败时显示简短原因与重试，绝不悄悄改画直线或切换引擎。地图提供者版权署名始终保留。
- 主题变化时重绘地图覆盖层颜色；响应式检查桌面、390px 与 412px，正式道路仍是主焦点，标记不遮挡关键信息，卡片无横向溢出。键盘与触屏均可操作开关和卡片，减少动效时不平滑滚动或播放加载动画。

## 数据与图层

- 只消费已生成的 `places[]`、逐日 `placeId`、`nearbyDays[]`、`dayRoadRoutes[]`；旧版 `explorationSegments[]` 继续可读。绘图前锁定中英文名称、城市/国家、WGS84 坐标、来源和核验状态。旧探索段仍维持 1–5 个已研究候选的兼容契约。
- 坐标优先官方地址/地图链接、受限地理编码服务或用户提供坐标；不得随机估算。仅估算时标注“景点坐标仅供参考，请以实际地图搜索为准”。
- 核对的是具体门店/景点 POI，不是嵌入地图视野中心、搜索中心或街区中心；URL 含经纬度不代表就是目标点位。先核名称、地址与分店，再采用明确的地点坐标；楼层、巷内入口或建筑入口与门店位置的差异写入已有地点/推荐说明。无法确认的坐标继续待核，不能以估算坐标满足逐日候选的核实要求。
- 日期视图的道路折线只来自 `dayRoadRoutes[]`；旧数据缺少路线几何时只显示点位并提示缺路线，不再画表示顺序的伪道路直线。时间与交通方案留在行程卡，不在地图重复标注。旧 A→B 探索视图只标起终点和候选点。
- `breakGroundRoute=true` 必须断开地面折线。日期与候选视图引用同一地点库；用户允许定位后只在当前浏览器显示位置并按大致直线距离排序，拒绝定位时仍可手选日期。附近候选不计算绕行时间，也不在卡片声称“真正顺路”。

## 加载与质量门禁

- Google 等待 JSAPI 最多 12 秒、首批底图最多 10 秒；任一超时均回收为可重试的错误状态，不得永久显示 Loading。
- 百度适配器只做一次诊断性重试；Google 与百度均不得自动降级到另一家。
- 本地地图验收使用私有配置已授权的固定 HTTP 来源和真实受限 Browser Key；检查首批底图、日期切换、道路几何、A/E 合并标记、候选开关与卡片双向定位、版权、控制台错误和 390px/412px 无横向溢出。证据写明实际来源和结果，不记录密钥；技能不写死本机端口，换电脑需核实私有来源授权。
- 自动测试覆盖引擎选择与超时契约；只有地图适配器、加载逻辑或地图密钥/来源配置发生变化时，才用纯中国大陆路线和境外/港澳台路线各做一次真实地图验收。普通攻略内容更新只验收该攻略受影响的地图内容，不重复跨引擎通测。
