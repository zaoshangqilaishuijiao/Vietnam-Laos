# 静态验收

## 静态验收

- 生成前：`node "<skill-root>/scripts/verify-template-lock.js"`；失败表示模板发生未登记漂移，只能暂停或进入用户确认的模板升级流程。
- 完整攻略：`node "<skill-root>/scripts/validate-guide-contract.js" <html> --full --expected-start=YYYY-MM-DD --expected-end=YYYY-MM-DD`；非连续日期改用 `--expected-dates=日期1,日期2`
- 同一攻略的后续版本在渲染报告中须有 `contentContinuity.status=enforced`；公开更新还须与该发布路径上一版正式 HTML 匹配。静态结构通过不代表前版内容被保留。
- 局部修改：`node "<skill-root>/scripts/validate-guide-contract.js" <html> --expected-start=YYYY-MM-DD --expected-end=YYYY-MM-DD --baseline-html=<旧版HTML>`
- `--full` 检查 UTF-8、乱码、HTML/CSS/可执行内嵌脚本、公共资产哨兵、唯一初始化入口、必需模块和 `data-guide-features` 条件模块；`application/json` 不做 JavaScript 语法检查。

## 全量回归

- 现场探索升级后，检查路线总览没有整程地图，逐日区域只有一个地图实例；每日日卡的地图入口能切换到对应日期，A→B 段能显示 1–5 个已核实候选及图片，拒绝定位和地图加载失败时仍能选择路段并查看详情。推荐图片的相对文件和作者/原帖链接必须被发布白名单包含；换汇对比缺任一费用时只显示“数据不足，无法比较”，不得计算伪净额。
- 附近逛逛另按 [逐日策略](nearby-explore.md) 覆盖：半日转场仍普通日、真正交通日、22:00 后入住/12:00 前离开边界、研究未完成阻断、全部合理隐藏、缺道路不阻断、旧 5–10 记录兼容。显示日允许无自由窗口与不绑定窗口的同城专程推荐；若填写窗口或索引，仍检查时间、锚点、缓冲、有效引用和城市，不用虚假窗口放行。跨目的地、缺图/作者/原帖/坐标仍须失败，不能把“价值优先”解释成免核验。
- 对改动攻略逐日核对状态、候选数量、隐藏原因与空界面；不以建议休息冒充无活动机会。检查每张新增/替换图片的实际对象与分店、POI 而非地图中心、天气/预约/专程提醒和互斥支线，避免只验证字段存在。内容判断由研究证据支持，静态校验不冒充已完成图片语义或推荐价值判断。
- 交互覆盖按日独立开关及跨日返回、卡片/标记双向定位及跨日同店定位、图片预览及失败、拒绝定位与地图失败降级、原时间线/交通/ICS 不变，以及重复初始化/销毁重建、键盘和减少动效；按改动检查桌面与 390px/412px。验收记录绑定当前输入、HTML 和相关资源哈希，区分静态检查、真实浏览器定向验收与发布级验收；部分通过不改写成整体通过，测试替身不计作真实底图通过。

- 首次使用或 `package-lock.json` 变化后，在技能目录执行 `npm ci`；Node 版本必须满足 `package.json.engines`。
- 若 `node` 不在 PATH，在 Codex 桌面先加载工作区依赖并使用其返回的 Node.js 可执行文件；不要把某台电脑的绝对运行时路径写入技能。
- 修改共享资产、数据契约、渲染器或静态契约后运行 `npm test`。单独运行 DOM 脚本时，缺少 jsdom 会打印安装提示并跳过；全量回归把缺少 jsdom 视为失败，避免在未执行交互测试时误报通过。
- 全量测试覆盖脚本语法、日期与页面契约、JSON→HTML 流水线、交互 DOM、模板锁、地图运行时，以及协作 Realtime、自定义事项回写和保存竞态。
- 安全与发布回归必须另外覆盖：`sb_secret_`/旧版 `service_role` JWT 被拦截，地点文本不能经路线汇总重新变成 DOM，已启用协作的基线不能无意降级，公开源 HTML 只含占位符，部署构建遇缺 Secret 时失败且不写出半成品。
- 首页模板修改后检查“英文标识与主题入口 → ITINERARY → 标题 → 摘要 → 底部事实”顺序，确认旧字段不会恢复入口或短评；浏览器至少验收390×844、412×915、1366×768与超宽桌面布局，封面必须完整覆盖可见视口且无页面底色白边。点击主题入口后确认浮层不遮满页面、不锁滚动，六套主题可切换且入口名称同步，关闭按钮、空白区域和 `Escape` 均有效。
- 组合工具修改后确认牛哞素材成功时替代 `…`，待机不持续抢动、滚动时使用跑步帧、停滚约 220ms 回待机、展开菜单时挥手；菜单按“今天、编辑、汇率、搜索”的条件顺序显示。模拟素材失败时必须仍可使用 `…`。在 `prefers-reduced-motion: reduce` 下角色保持静态，并检查搜索面板与牛哞入口在手机安全区内不重叠。启用汇率时确认弹窗双向输入、币种切换、美元参考行、动态心算和焦点回返；预算正文不重复放置汇率卡。

## 预定清单验收

预定清单的数据与交互契约只在 [booking-ledger.md](booking-ledger.md) 维护。本文件要求全量回归覆盖 `checklist → bookings → recommendations → sources`、预订三态、本地保存、协作映射、服务器回写后 `.booking-status` 保留，以及当地体验独立导航、场所锚点和重复地点去重。

发布验收结果按 web-output-and-publishing.md 记录实际证据及源/产物/资源哈希。六项名称本身不能作为通过证明。模板升级完成后统一运行全量回归；真实外部服务未验证时明确保留限制。
