# 旅行攻略制作 2.52.0 - 详细规则

## 不可变原则

- `trip-data.json` 是内容唯一真相源；HTML 只呈现，不补写事实、不改变路线。`places[]` 是地点唯一真相源，其余模块只引用 `placeId`。
- 共同编辑只处理执行状态，不得在线修改路线、日期、地点、逐日时间线、交通、预算基准、地图点位、风险提示或资料来源；这些内容只能改 JSON 后重新渲染。
- 普通新攻略只填充三份过程 JSON；不得改渲染器、章节 DOM、共享 CSS、交互脚本、断点或组件模板。
- 不虚构地点、坐标、来源、班次、开放状态、价格或政策；核心事实未知时写"待核验"并给出核验路径。可选的风险、替代、备注、提示、限制或执行建议没有实质信息时直接省略，不得用“待核验”占位。
- 私人资料只在本地处理。未经授权不公开、不上传、不批量删除。
- 有明确日期时必须建立连续或显式日期清单；不得缺日、重复、乱序或擅自缩短。
- 公开 Git 提交或推送前必须检查作者、提交者与待推送提交；禁止组织/公司内部邮箱。命中即停止，改用已确认的 GitHub noreply 或个人公开邮箱。

## 授权与工作流

- 用户说“生成攻略”先完成研究与文字稿，文字内容确认后再生成网页；明确说“直接做完网页、无需中途确认”时可一次授权两阶段。只询问会实质改变路线、预算或安全判断的关键缺失信息，不就同一内容反复确认。
- 研究受平台拦截时停止该平台访问，记录已读数量与缺口；按研究规则使用允许范围内的替代官方或本地证据，证据不足才暂停，不绕过访问限制。
- 研究完成后先展示含现场探索、具体商品、换汇渠道和出入境样本的文字稿及证据缺口；用户确认或已明确授权直接做完时，再进入网页生成。
- 用户说"生成网页"即完成本地最终 HTML；"上传/发布"即发布当前目标所需的最终网页及相对资源。过程 JSON、基线和报告只留本地；只有目标不明、身份门禁、敏感信息、文件范围或远端冲突时暂停。

## 强制内容结构

完整攻略按如下顺序输出；必需的核心事实不足时写"待核验"或"不适用"，不可静默省略；可选补充说明没有信息价值时必须省略：

1. 首屏：本地目的地实景封面、英文手册标识、右上角透明玻璃主题入口、固定英文眉题 `ITINERARY`、原创中文主标题、路线摘要和底部三项旅程事实；封面始终占满当前可见视口，默认海岸蓝且可由 `meta.theme` 调整语义颜色；不生成“查看行程”入口、图片来源、目的地短评，预算口径与完整路线留在正文；
2. 到达 / 离开（实际跨越中国大陆边境或国际/地区出入境时）；
3. 路线总览（仅文字站点概览；整程地图不再生成）；
4. 逐日行程（含共用的当天道路地图和“附近逛逛”开关；旧 A→B 路段探索只保留兼容）；
5. 城际与市内交通；
6. 预算与汇率；
7. 出发前核验清单：证件、签证/入境、安全、交通、预约、支付、气候与天气；天气始终在可编辑事项之后；
8. 预定清单；
9. 当地体验：景点、体验、餐饮、文创，以及按适用性选择文化特点、会客礼仪、文化禁忌卡片的文化习俗；与预定清单相邻但保留独立快捷导航；
10. 资料来源。

资料来源按核验用途分组展示，固定顺序为：行程原始资料、入境与交通、景点与预约、餐饮与购物、文化习俗、天气与汇率、其他官方资料、小红书经验。空分组不渲染；重排只能改变展示位置，不得改变来源 `id`、`#source-{id}` 锚点或正文角标。

主章节顺序与标题以 `module-registry.json` 为机器侧唯一真相源，副标题按内容生成。导航由实际存在的章节自动生成；到达/离开、汇率与天气由功能开关决定。完整攻略默认启用资料索引和高级来源搜索；逐日行程固定为实际天数的日期 Tab 与单卡切换。

## 模板与数据边界

- 模板锁定范围：章节顺序/标题、DOM 契约、导航/搜索/地图/清单/天气/汇率/日历/支出交互、设计令牌、卡片与表格、响应式断点和降级文案。
- JSON 可变范围：事实内容、日期、地点、路线、来源、预算、天气地点、推荐、核验项和合法功能开关。
- 用户提出新章节或交互属于模板升级：先说明影响，获确认后修改共享资产；必须提升 `PAGE_TEMPLATE_VERSION`、更新 `page-template.lock.json`、补充契约测试并跑全量回归。不得只改单篇生成 HTML 或将一次性例外静默固化。

## 内容决策基线

- 先排城市，再排日节奏；强度为 0–5、每 0.5 递增的 🌟。抵离/跨城日降低强度，返程前一天避免高风险远郊。
- 仅中国大陆地点使用百度 JS API GL；涉及境外或港澳台使用 Google Maps JavaScript API。密钥只从私有本机配置读取。两者都必须保留动态缩放、平移、Marker、Polyline、方向、交通与时间标签；禁止整张截图或 AI 图作底图。
- 预算以 CNY 作为基准币；外币原价与换算口径写备注。汇率、天气首次加载不联网，仅用户手动刷新。
- 小红书体验用于线索；政策、警报、班次、开放状态与价格以官方来源核验。研究数量、专项边界和受阻止损只按 `research-and-sources.md` 执行。
- 新攻略默认启用 `nearbyExplore`，逐日状态、普通日 3–5 / 真正交通日 1–3、晚到早离例外及道路缺段按 [附近逛逛策略](nearby-explore.md)；候选具图、具原帖、具坐标，研究未完成不得伪装为无自由窗口。旧 `contextualExplore` 仅兼容既有攻略。夜市写到具体商品，汇率对比写具名渠道和完整费用；证据不足时显示“无法比较”。已生成旧数据不因缺少新增字段而失效。

## 验收与交付

- 生成前必须通过 `scripts/verify-template-lock.js`；内容先通过 `validate-trip-data.js`，完整 HTML 再通过 `validate-guide-contract.js --full`。
- 浏览器验收按改动范围检查桌面/移动端、横向溢出、导航、搜索、复制、清单、天气/汇率、地图与控制台。完整交付或发布做全量验收，局部改动做定向验收。
- 最终回复只给用户所需的成品路径、结构化数据路径与验证结论；不粘贴整份 JSON 或 HTML。
